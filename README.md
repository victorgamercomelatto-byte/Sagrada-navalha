# Sagrada Navalha

Site institucional da barbearia Sagrada Navalha. O projeto apresenta a barbearia, seus serviços, equipe, galeria, produtos e informações de localização.

## Arquivos

- `index.html`: página principal.
- `about.html`: página sobre a barbearia.
- `css/` e `js/`: estilos e scripts do site.
- `img/`: identidade visual e imagens utilizadas nas páginas.

Abra `index.html` no navegador para visualizar o site localmente.

## Créditos

Projeto personalizado a partir do template Fade, de uiCookies: https://uicookies.com/.
